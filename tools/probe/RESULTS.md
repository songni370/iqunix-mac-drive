# 真机实测结果（2026-10-19，macOS 26.6.2 / Apple Silicon）

以下为 `tools/probe/` 在本机 IQUNIX MQ80 上的原始输出摘录。

## 1. 设备与接口

```
IFACE page=0xFF60 usage=0x61 in=32 out=32 feat=0 loc=0x3140000
  reportDescriptor(34):
  06 60 FF 09 61 A1 01 09 62 15 00 26 FF 00 95 20 75 08 81 02
  09 63 15 00 26 FF 00 95 20 75 08 91 02 C0
```

- 匹配到 4 个 HID 接口：`0xFF60/0x61`（VIA Raw HID，32B in/out）、两个 `0x0001/0x06`（键盘）、`0xFF1C/0x92`（厂商私有，8B in / 63B out，Report ID 4）。
- 首次 `IOHIDManagerOpen` → `0xE00002E2`；授权「输入监控」后 → `0x00000000`。`IOHIDDeviceOpen(rawHID)` → 0。

## 2. 协议版本 / 层数 / 键位

```
> 01        -> 01 00 0B ...        协议版本 0x000B (11)
> 11        -> 11 04 ...           4 层
> 12 00 00 04 -> 12 00 00 04 00 00 00 3A ...
> 12 00 00 1C -> 12 00 00 1C 00 00 00 3A 00 3B 00 3C ...
```

- 键位读取：4 层 × 256 字节，共 1024 字节。
- Layer 0 与 Layer 1 有 30 个键不同（Layer 1 为 Fn 层：媒体/RGB/自定义键）；Layer 2/3 与 Layer 0 相同。
- `(7,14)` = `0x5221`（`MO(1)`，Fn 键）。

## 3. 键位写入验证

```
> 13 00 C0 02 00 04 ...    写空位 (r6,c0) = 0x0004
< 13 00 C0 02 ...          回显
> 12 00 C0 02 ...          回读
< 12 00 C0 02 00 04 ...    keycode = 0x0004 ✅
> 13 00 C0 02 00 00 ...    还原
< 12 00 C0 02 00 00 ...    keycode = 0x0000 ✅
```

## 4. 灯效（channel 3）

```
> 08 03 01 00 -> 08 03 01 05   brightness = 5
> 08 03 02 00 -> 08 03 02 01   effect = 1 (WAVE)
> 08 03 03 00 -> 08 03 03 02   speed = 2
> 08 03 04 00 -> 08 03 04 00 FF  hue=0x00, sat=0xFF

> 07 03 01 05 -> 07 03 01 05   写亮度 5
> 08 03 01 00 -> 08 03 01 05   回读 5 ✅
> 09 03 01    -> 09 03 01      保存 ✅
```

## 5. 宏

```
> 0C -> 0C 10          16 个宏槽
> 0D -> 0D 02 00       512 字节缓冲区
> 0E 00 00 08 -> 0E 00 00 08 FF FF FF FF ...   空（全 0xFF）
> 0F 00 00 05 54 45 53 54 00 -> 回显
> 0E 00 00 08 -> FF FF FF FF ...                写入未持久化 ⚠️
> 10 -> 回显；缓冲区仍为 FF
```

结论：宏读取可用，写入语义待进一步验证（尤其 VIA 官方「写前重置 + 末字节标记」时序）。

## 6. 非标准响应

```
> 02 01 / 02 02 / 02 04 / 02 06  -> 均为 02 03 00 00 ...   （keyboard value 不可用）
> 04 00 00 00 -> 01 00 09 00 ...   （标准应为 04 00 00 00 kc_hi kc_lo）
> 16 01 00 00 -> 01 01 09 00 ...   （UI_SYNC 不支持）
> 7E          -> 01 00 09 ...       （未知命令也返回非标准应答）
```

## 7. 测试后的恢复状态

- 灯效：亮度 5 / 效果 1（WAVE）/ 速度 2 / 色相 0 / 饱和度 255 —— 与测试前一致。
- 键位：临时改写的空位已还原为 `0x0000`。
- 宏：缓冲区为空（全 `0xFF`），与测试前一致。
